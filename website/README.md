# 網站主題瀏覽與標籤

正式資料：data/tags.json 是標籤名稱與瀏覽分組；data/article-tags.json 是文章對應。台灣／中國公司使用「英文 中文」，其他標籤英文；網址參數使用顯示名稱編碼。

分組是瀏覽入口，不是父子分類。同一標籤可出現在多組，共用選取狀態。多選取交集；搜尋採不分大小寫的包含字詞比對，支援中文；不另外放 A–Z。

pages/ 保存 2026-10-24 已發布 WordPress HTML 快照，包含搜尋、篩選與文章索引。目前採自訂 HTML，非 WordPress 原生 post_tag taxonomy；新增文章不會自動收錄。更新資料後須同步雙語頁面及文章開頭的 ians-article-tags 區塊，驗證公開頁面再更新快照。不得只改 JSON 就宣稱已部署。

正式網址：https://iansnotes.com/zh/topics/ 與 https://iansnotes.com/en/topics-en/ 。文章標籤位於日期下方、正文之前。

## 寫作流程

寫稿時先查完整標籤庫，再依全文充分提出相關公司、產品、模型、技術、應用、記憶體世代及代工廠＋製程候選；優先沿用既有名稱，新標籤標示新增。不因想湊齊分類而補文章沒提到的項目，不從產品型號推測代工廠或製程。候選先多放，交 Ian 用打叉刪除的頁面審閱；確認後才更新文章與索引。影片／文字版共用同主題標籤，中英文對應文章保持一致。

模型名稱依內文保留；製程採 TSMC N2、TSMC N3、TSMC A16；記憶體保留 HBM 大類與實際提到的 HBM4e。審閱前不以模型偏好替 Ian 大幅刪減。

公開庫只放公開文章與前端資料。後台備份、cookie、token、訂閱者 email、私人投放報表留在私人環境，不能複製整個任務工作目錄。
